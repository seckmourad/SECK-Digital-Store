# SECK DIGITAL STORE — النسخة الأولية

## ما الذي يعمل الآن؟
- واجهة متجر عربية متجاوبة مع الهاتف.
- تصفية المنتجات حسب الفئة.
- اختيار منتج وباقة.
- نموذج طلب تجريبي.
- حفظ الطلبات محلياً على الجهاز باستخدام LocalStorage.
- manifest وService Worker كبداية لتطبيق PWA.

## ما الذي لا يعمل بعد؟
- لا يوجد خادم أو قاعدة بيانات مشتركة.
- الطلبات لا تصل إلى صاحب المتجر؛ تحفظ على الجهاز الذي أنشأها فقط.
- لا يوجد دفع حقيقي أو تحقق من التحويلات.
- الأسعار والباقات المعروضة تجريبية، ويجب استبدالها بالأسعار المعتمدة.
- لا يوجد ربط بمورّد شحن أو تنفيذ تلقائي.

## التشغيل
يمكن فتح index.html لمعاينة الواجهة. لاختبار التثبيت والعمل دون اتصال، ارفع المجلد على استضافة HTTPS تدعم الملفات الثابتة. يمكن استخدام استضافة مجانية مثل GitHub Pages أو Cloudflare Pages.

## قبل الإطلاق الفعلي
1. تحديد الأسعار والمورّدين وشروط الشحن.
2. إنشاء Backend وقاعدة بيانات آمنة للطلبات.
3. إنشاء لوحة إدارة خاصة.
4. ربط وسائل الدفع المحلية بعد الحصول على موافقة/تكامل رسمي.
5. إضافة سياسة خصوصية وشروط استخدام ودعم العملاء.
6. اختبار التطبيق على أجهزة Android وiPhone.
